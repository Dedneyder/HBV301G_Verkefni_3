# Vinnuferli

## Hópavinna og geymsla 

Í hópnum eru Björgvin Þeyr Guðmundsson og Konráð Jóel Jónasson, við skiptum upp verkefnunum Konráð: BO-1,BO-2,Framtíðasýn og Vinnuferli. Björgvin:Prófíll lykilhagsmunaaðila eða mikilvægra notenda, Forgangsröðun verkefnisins, Umfang fyrstu útgáfu (MVP) og BO-3. Git repository er [HBV301G_Verkefni_3](https://github.com/Dedneyder/HBV301G_Verkefni_3). Við vorum báðir að pusha og gera pull request af viðeigandi branch á main.

## Verkaskipting
- Við skiptum verkefnum eins og kemur fram í Hópavinna og geymsla. Við gerðum branch fyrir hverja kröfu t.d BO-1,BO-2 voru saman á branch og Vinnuferli var í sér branch.
- Ég bjó til issue sem Björgvin tók að sér að gera gerði pull request og ég fór svo yfir það pull request og ef mér fannst það gott mergeaði ég því eða commentaði í issue til að laga. hann gerði hið sama fyrir mig.
- Byrjuðum á að uppfæra main branchið með því að framkvæma pull. Næst var búið til nýtt branch út frá main, breytingar voru vistaðar með commit á því branchi og síðan var branchið pushað til að geta stofnað Pull Request.

## Ígrundun
- Í lok verkefnis gerið endurmat á verkefninu:
    - Samskipti innan hópsins voru mjög góð. Verkferlið sem við ákváðum í upphafi var notkun á issues og pull requests það gekk vel og auðveldaði samvinnuna.
    - Okkur fannst verkefnið almennt ganga vel fyrir sig og markmiðum þess var náð.

### Gagnsæisyfirlýsing um notkun gervigreindar

Ef þið notið gervigreind við vinnslu verkefnisins skal koma fram:

- Chat-gpt og Copilot var notað til að yfirfara málfar.
- Promtin sem voru notuð: Farðu yfir málfar textans án þess að breyta merkingu hans, vantar eitthvað í verkefnið miðað við verkefnislýsingu? 
- Gervigreindinn var notuð aðalega til að athuga hvort verkefni uppfylti verkefniskröfur og hvort verkefnið væri í skilanlegu ástandi.
- Tillögur frá gervigreind voru yfirfarnar og aðlagaðar að okkar verkefni.

Við staðfestum að við höfum yfirfarið allt efni sem gervigreind lagði til og breytt eftir þörfum. Við berum ábyrgð á öllu efni sem skilað er í verkefninu.
